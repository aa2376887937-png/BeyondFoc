## 二、已实现内容

### 2.1 已用算法

#### 坐标变换
- **Clarke 变换**：三相 → αβ，提供完整版（三相都采）和简化版（只采两相，利用 ia+ib+ic=0）。
- **Park 变换 / 逆 Park**：αβ ↔ dq，需要电角度 sin/cos。
- **逆 Clarke**：αβ → 三相，用于死区补偿中的电流方向判断。

#### 调制
- **SVPWM（中点注入法 / 七段式）**：不做扇区判断，直接算三相调制度的中点作为共模分量注入，占空比 = 0.5 + (相调制度 − 中点) / √3。线性调制区可达母线电压的 1/√3，比 SPWM 高 15.5%。
- **过调制保护**：比较值限幅到 [0, period]，不归一化，保持三相相对关系。
- **扇区判断函数**（`Svpwm_Sector`）：仅用于调试观察，不参与计算。

#### 电流环
- **dq 电流 PI**：d/q 各一个 PI，参数按带宽整定（零极点对消：`Kp = ω·L`，`Ki = ω·R`），当前电流环带宽 1 kHz。
- **PI 离散化**：梯形积分 `I += Ki·T/2·(e[k] + e[k-1])`。
- **抗积分饱和**：条件积分，输出饱和且积分方向继续推饱和时冻结积分；积分限幅独立配置。
- **积分分离**：误差大时积分权重按 smoothstep 连续降到 0（比硬切换平滑）。
- **交叉解耦 + 反电势前馈**：
  - `vd -= ωe·Lq·iq`
  - `vq += ωe·Ld·id + ωe·ψf`
  - 通过 `Set_Decoupling(DECOUPLING_CROSS_BEMF)` 启用。
- **电压圆限幅（d 轴优先）**：`vd² + vq² ≤ Vmax²`，先保 vd，q 轴用剩余电压；积分限幅取整个圆半径（避免 vd 大时 q 轴积分被拆掉）。
- **死区补偿**：S 曲线模型，补偿电压 = `Vbus·td·fs` + 管压降，过零区用 `I/(|I|+knee)` 平滑；方向由 `kDtCompSign` 决定（实测 −1）。
- **NaN / 越界保护**：占空比非法时退回 0.5（零矢量），避免三路全开。

#### 电流采样
- **ADC 码值 → 安培**：`I = (ADC − 零点) / 满量程 × Vref / (R × 增益)`。
- **零偏校准**：功率级关断时采样求均值，先丢弃 settle 段再累加。
- **3 点中值滤波**：对每相电流做 Med3，抑制单点 ADC 毛刺。
- **1 ms 窗口平均**：只用于遥测显示，控制环仍用瞬时值。

#### 角度与转速
- **sin/cos 查表**：1024 点 + 线性插值，误差 < 1e-5，比 newlib 的 sinf/cosf 快很多。
- **电角度零位标定（多点矢量平均）**：
  - 8 个电角度（每 45°）依次用 d 轴小电流吸住转子，读编码器原始角，得 `offset_i = θ_i − raw_i`。
  - 对 8 个 offset 做单位圆矢量平均（避免 ±π 附近算错）。
  - 离散度 > 15° 判失败，不覆盖旧 offset，用于检测编码器安装偏心或方向错误。
- **MT6701 解码**：CRC6（多项式 0x43）校验；全 0 / 全 1 帧丢弃；跨零展开（增量累加，`mech_deg` 连续多圈）。
- **帧可信度检查**：比较相邻两帧隐含速度，突变超阈值则拒绝该帧并外推角度；连续 3 帧偏离才重新同步。
- **速度估计（二阶 PLL）**：角度误差 → PI 环路滤波 → 积分得角度，连续角度估计；带宽 80 Hz，阻尼 0.707。积分限幅 ±200 rad/s。
- **角度外推**：中断里用 `角度 + 速度 × Δt`（Δt 由 DWT 时间戳算，上限 2 ms），补偿监控任务 250 µs 节拍带来的延迟。用序号锁（seqlock 思想）保证读到的角度/速度/时间戳是同一组。
- **开环角度发生器**：强拖模式下的斜坡加速（避免过流/失步），SVPWM 输出。

#### 位置环与转速环
- **转速环 PI**：4 kHz（电流环的 5 分频）。Kp/Ki 由惯量和 Kt 推导：`A = (60/2π)·Kt/J`，`Kp = 2π·30 / A ≈ 0.0218`，`Ki = Kp·13`（零点 2 Hz）。
- **转速目标斜坡**：可配置 rpm/s，默认关闭。
- **位置环 PD**（800 Hz）：
  - `speed_ref = Kp·e − Kd·v_actual + Ff·v_plan`
  - D 项一阶低通（30 Hz），抑制编码器速度量化噪声。
  - **带回差的小死区**：进入 0.4° 清零误差，超过 0.8° 才重新接管，防止静态抖动。
  - 速度前馈 + 输出速度限幅。
- **ADRC 的 TD 轨迹规划**（`fhan` 最速控制函数）：已实现，默认关闭。

#### 辨识与测试
- **扫频（Bode 测量）**：电流环 5 Hz–2 kHz、转速环 0.3–800 Hz，对数分布 20 点。在 20 kHz 中断内生成正弦激励，**I/Q 同步解调**得幅值（dB）和相位，回传上位机画 Bode 图。
- **Ld/Lq 辨识**：d、q 轴分别注入 1 kHz 正弦电压，解调测电流幅值，`L = √(Z² − R²) / ω`，每轴 4 次取中位数。

#### 备用/旁路
- **滑模观测器（SMO）**：电流观测器 + 饱和函数（边界层 φ 代替 sign）+ 等效反电势低通 + PLL 出角度。自动整定：`g ≤ 0.8·(2L/dt − R)`，`φ = 2·emf_max/g`。**当前 `kUseSmo = false`，仅旁路运行，未参与控制。**

### 2.5 电感测量的原理：为什么正弦注入行、电压阶跃不行

> 两种方法共用同一个物理方程，差别只在**怎么测电流变化**。

静止时 dq 轴电压方程：

```
V = R·i + L·di/dt
```

只要测出加电压后电流的变化速率 `di/dt`，就能反推电感：

```
L = (V − R·i) / (di/dt)
```

#### 阶跃法：直接用瞬态，测 1~2 个点的差值

加 `V = 1 V`，持续 2~4 个 PWM 周期（100~200 µs），测第一拍和第二拍的电流差 Δi，`L = V·Δt/Δi`。

问题在于它**只靠 1~2 个采样点的差值**，对时序极其敏感：

1. **致命伤：PWM 影子寄存器**。比较值有预装载（`TIM_CCMR1_OC1PE`），本拍写的电压要下个 PWM 周期才真正加到绕组。于是：
   ```
   tick k   写 Vd = 1V   → 下周期才生效
   tick k+1 采样        → 这个电流还是"没加电压"时的值
            → Δi ≈ 0 → L = V·Δt/0 → 无限大 → 判无效 → 返回 0
   ```
   这就是阶跃法**一直返回 0**的根因。要么猜延迟拍数（猜错还是 0），要么加长阶跃（1V/37µH ≈ 27 A/ms，会过流）。

2. **Δi 只有 0.6~1.2 A**，单点噪声 ~20 mA，一次测量就有 2~3% 误差。
3. **死区/管压降**在 1 V 短脉冲里占好几个百分点。

#### 正弦注入法：用稳态幅值，测几百个点

加 `V·sin(ωt)`（1 kHz、0.5 V），稳态后电流是 `I·sin(ωt + φ)`。用同相 sin/cos 做 **I/Q 解调**，20 个周期共 400 点求幅值：

```
I_acc = Σ i·sin(ωt)     Q_acc = Σ i·cos(ωt)
I     = 2·√(I_acc² + Q_acc²) / N
Z     = V / I
L     = √(Z² − R²) / ω
```

#### 关键差异：幅值对延时 / 相位不敏感

影子寄存器晚 1~2 拍、ADC 采样点偏一点，都**只旋转电流的相位 φ，不改变幅值 I**；而 I/Q 解调求幅值 `2√(I²+Q²)/N` 与 φ 无关。

| 问题 | 阶跃法 | 正弦法 |
|---|---|---|
| 影子寄存器延时 | Δi → 0，L 判无效 | 相位偏移，幅值不变 |
| 噪声 | 1~2 个点 | 400 个点平均 |
| 电流峰值 | 4~7 A | ~1 A（0.5 V @ 1 kHz） |
| 死区/管压降误差 | 短脉冲里占比大 | 恒定比例，可标定 |

一句话总结：

> 阶跃法测的是"两个采样点的差值"——差一拍就是 0；正弦法测的是"几百个点的幅值"——延时和噪声都被平均掉了。正弦法把一次性的瞬态测量，变成了稳态的、可积分的测量。


### 3.4 设计原则（可以作为以后写代码的参照）
1. **算法纯函数化**：输入输出是结构体，不持有硬件指针。
2. **中断内只做计算和读写寄存器**，不做组帧、解析、printf。
3. **共享数据用 Latest（允许覆盖）或 SpscRing（不能丢）**，不用互斥量阻塞中断。
4. **临界区要短**：`taskENTER_CRITICAL` 只包住状态读写。
5. **NaN 防护**：所有可能输出到 PWM 的值都要检查，避免变成 0 占空比导致三路全开。
6. **参数集中**：业务选择（参数、开关）在 `app_config.h`，算法不写死数字。

| **输出端编码器（双编码器）** | 减速器后的输出角度，用于补偿减速器回差和柔性形变 |
| **摩擦补偿** | 库仑摩擦 + 粘滞摩擦，低速爬行时效果明显 |
| **齿槽转矩补偿** | 永磁电机转矩脉动的主要来源之一，可用查表或傅里叶补偿 |
| **编码器误差补偿** | 利用 8 点标定的残差拟合一个 `θ` 相关的修正表，抑制安装偏心带来的 1–3° 误差 |
| **无感观测器（SMO 投入使用）** | 作为编码器失效时的备份；`kUseSmo` 目前关闭 |
| **Ld/Lq 辨识结果回写** | 辨识出的 L 目前只在上位机显示，应接入解耦和 MTPA |

### P2：高级功能（有余力再做）

- **自动参数辨识（Rs、ψf、J、摩擦）**：把现有辨识流程做成一键完成。
- **模型预测控制（MPC）或状态反馈**：替代 PI 的高带宽电流环。
- **热模型**：用电流平方积分估算绕组温度，取代单纯的 NTC 阈值。
- **固件 OTA / Bootloader**：量产必需，目前无。
- **功能安全**（看门狗、双通道采样校验）：机器人关节可能涉及人身安全时必须考虑。

## 五、需要深耕的地方

这些地方不是"能跑就行"，而是决定关节模组最终性能和可靠性的核心，建议花大量时间钻研。

### 5.1 电流环（最核心）
- **采样时序**：ADC 注入触发点与 PWM 中心对齐，关注**中点采样**的时刻和死区/消隐时间的关系。
- **死区补偿的标定**：目前 `kDtCompSign = −1` 和 `kDtCompKnee = 0.15 A` 是靠经验调出来的，需要理解 S 曲线原理，系统标定管压降和死区。
- **电流环带宽与采样延迟**：20 kHz 采样 + 50 µs 周期，电流环 1 kHz 带宽只有 1/20 余量，要用 Bode 图（扫频功能已有）验证相位裕度。
- **解耦的鲁棒性**：ωe·Lq·iq 依赖 Lq 精度，Lq 误差会直接影响动态耦合。

### 5.2 参数辨识与整定
- **Ld/Lq 辨识精度**：当前用正弦注入，要分析：电流幅值小时噪声的影响、频率选择（1 kHz 接近电流环带宽）、温度对 Rs 和 L 的影响。
- **PI 整定方法**：目前是带宽法（零极点对消）。要理解为什么 Ki = ω·R 而不是别的值，并用扫频结果做闭环验证。
- **转速环和位置环的整定**：转速环用惯量 J 推导，J 的实测方法要搞清楚（可以用加速度法或扫频反推）。

### 5.3 编码器与角度
- **编码器误差是关节精度的天花板**：MT6701 的非线性、安装偏心、磁铁偏心都会造成周期性误差。要学会用谐波分析定位问题（8 点标定的残差就是第一步）。
- **速度估计的带宽/噪声权衡**：PLL 80 Hz 带宽是怎么选的，低速时的量化噪声怎么办，这是关节低速平稳性的关键。
- **延迟补偿**：角度外推只是一阶近似，高速时要分析残余误差对 dq 解耦的影响。

### 5.4 调制与功率级
- **SVPWM 的谐波与 EMI**：PWM 频率选择、死区、开关边沿对采样的干扰。
- **三电阻采样的限制**：低占空比区域只能采样一相甚至不能采样，要理解**最小脉宽**和**重构误差**，这是低速性能的瓶颈之一。
- **母线电压波动与过调制**：高速或低母线时的电压饱和行为。

### 5.5 机械与热
- **减速器**：回差、柔性、效率，直接影响力矩控制精度。
- **热设计**：电流长期运行的温升，要结合热阻建模。
- **转矩脉动**：齿槽转矩 + 反电势谐波，决定低速平稳性和噪声。

### 5.6 系统与可靠性
- **实时性**：中断占用率（ISR avg/max）要长期监控，给后续功能留余量。
- **故障注入测试**：断线、编码器丢帧、电流突变、短路，每种情况下模组应进入什么状态，需要写成测试用例。
