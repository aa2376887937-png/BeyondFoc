## 2026-11-09

### 新增

- **电流环调试到 1kHz**：Kp_d=0.2350、Kp_q=0.3971、Ki=1162，按零极点对消整定。
- **反算抗饱和（Back_Calc）**：电压圆限幅后把 `v_sat − v_pi` 回灌积分器，替代简单的积分限幅。
- **角度外推**：编码器帧 + 电角速度外推 1.5 个 PWM 周期，补偿采样/计算延迟。
- **过温保护状态机**：绕组 80°C 降流、100°C 停机、驱动 90°C；8°C 回差；NTC 异常按 25°C 处理。
- **Rs 温补**：0.4%/°C，只改 Ki 不动 Kp。
- **双 NTC 温度遥测** + 上位机顶栏显示。
- **扫频**：电流 5–2000Hz、转速 0.3–800Hz，板内 20kHz/4kHz 生成 + I/Q 同步解调。
- **Ld/Lq 正弦阻抗辨识**：1kHz、0.5V、4 次取中位数，带静止守卫。
- **上位机**：谐波 FFT 页签、电角度曲线、J/B 惰行法辨识、g·cm² / mN·m·s 单位。
- **SPI 提速**：664kHz → 5.31MHz → 10.625MHz（`SPI_BAUDRATEPRESCALER_16`），帧产出限 20kfps。

### 修改

- **采样触发改硬件**：TIM1 TRGO(=OC4REF, `CCR4 = 5% ARR`) 触发 ADC1 注入组，软件不再启动转换。
- **影子寄存器关闭**：清 `OCxPE`，CCR 写入立即生效，采样→计算→PWM 连贯。
- **死区补偿改用瞬时电流**（`i_abc_meas`），三次多项式过渡。
- **SPI 帧在 20kHz 电流环中断里消费**，Monitor 只保留看门狗。
- **遥测帧扩到 145 字节**（payload 140），新增 `motor_temp` / `driver_temp` / `thermal_state`。

### 删除

- **Med3 中值滤波**：3 点中值 = 1 拍延迟，1kHz 带宽下约 18° 相位损失，反馈改为直通。
- **解耦前馈的 dq 低通**（当天先保留，11-10 删除）。

### 问题与解决

| 问题 | 现象 | 根因 | 解决 |
|---|---|---|---|
| CORDIC 半波/直流偏移 | 扫频波形只有半波或整体上移 | 角度折叠用 `a - int(a)`（mod 1.0），但 Q1.31 满量程 1.0 = π，折叠周期应是 2.0 | 改为 `a -= 2*floor(a*0.5+0.5)`，数值验证 0/±π/2/±π/±10 全部正确 |
| 电流反馈噪声/毛刺 | 低电流时 id 抖 | 采样窗口 || 采样点落在零矢量窗口内，去掉中值滤波 |
| 编码器重复帧 | 速度偶发尖峰 | `Latest` 是邮箱不是队列，无新帧时反复返回同一帧 → dt_s=0 → 兜底 1ms | 用帧时间戳去重（`last_taken_cycles`），dt 兜底改 250µs |
| 坏帧计数 | 偶发 CRC 错误 | 6bit CRC 单比特错误有 1/64 概率通过 | 加隐含速度可信度检查，连续 3 帧偏离才重新同步 |

### 新增

- **正弦速度测试修正**（3 处）：
  1. 正弦参考从 1kHz 任务移到 **4kHz 速度环节拍**生成（50Hz 时 20 点/周期 → 80 点）。

- **PLL 输出一阶低通**：`kPllSpeedFilterHz`，用真实帧间隔 `dt_s` 算系数，帧率变化不用改参数。
- **位置环最速轨迹规划**：相位平面开关线 `σ = d − v|v|/(2a)`，加速度只有 ±a_max，越过目标即落位。

- **PI 位置式/增量式切换**：flags bit4，上位机复选框，切换时状态对齐、无扰。
- **板内捕获**：
  - 1024 点 × 4 路，电流 20kHz / 转速 4kHz 原始采样。
  - 新帧类型 `0x02`，每帧 8 点，128 帧 ≈ 128ms 传完。

  - 上位机新增「捕获」页签 + 单次捕获按钮。
- **上位机布局重构**：左侧改 3 个页签（运行 / 整定 / 测试），显示与视图移到「波形」页顶部。
- **深蓝主题**：窗口/分组/按钮/页签/输入框/波形背景统一成海军蓝配色。
- **MIT 阻抗控制**：新增 `MODE_MIT`，4kHz 计算
  `τ = Kp·(θd−θ) + Kd·(ωd−ω) + τff`，再换算成 iq 走 20kHz 电流环。
  - 不经过转速环（转速环积分会把外力当误差吃掉，失去背驱透明性）
  - 位置目标斜率限制、Kp/Kd 软启动（100ms）、位置误差限幅、力矩限幅（上位机/电流上限/温度降流取最小）
  - 上位机加 MIT 参数（目标位置/速度、Kp、Kd、前馈力矩、力矩限幅）
- **在线磁链辨识（方法一）**：
  `ψf = (vq − R·iq − ωe·Ld·id)/ωe`，1kHz 计算，1Hz 低通。
  - 门控：|ωe| > 300rad/s、|iq| > 0.2A、电压未饱和、非扫频、编码器有效
  - R 用温补后的值；合理性限幅 0.5~1.5 倍标称

  `L = sqrt((Z2²−Z1²)/(ω2²−ω1²))` 消掉 R；`R = sqrt(Z1²−(ω1L)²)`。
  注入电压 0.8V，加测试中转速守卫。
- **L 辨识触发改一次性标志位**（flags bit8），不再依赖 test_type 边沿。

### 问题与解决

| 问题 | 现象 | 根因 | 解决 |
|---|---|---|---|
| 正弦速度偶发尖峰 | 给正弦速度时速度曲线有尖峰 | ① `Latest` 重复消费同一帧 ② dt 兜底 1ms 是真实周期的 4 倍 | 帧去重 + 兜底改 250µs；正弦参考移到 4kHz |
| 速度环 100Hz 振荡/啸叫 | 提到 100Hz 后电流啸叫 | 80Hz PLL 在 100Hz 处相位 −106°，相位裕度为负 | 先用 400Hz PLL；后按参考设计改成 95.5Hz PLL + 30Hz 速度环 |
| 死区补偿符号疑问 | 用户问"是 +1 还是 -1" | 文档里写"±1 是试出来的"，无推导 | 推导：死区误差 = −(Td/Ts)Vbus·sign(i)，补偿应为 +sign(i)；因电流环稳定条件 γσ=+1，结论是 **+1**。但当前配置仍为 −1（待实测确认） |
| 死区补偿以 MOS 压降为主？ | 12V 下压降项占 34% | 把 MOS 导通压降当成了死区效应 | MOS 压降属于回路电阻，由电流环积分处理；`kDtCompDrop=0` |
| PLL 积分限幅卡转速 | 高转速时速度估计上不去 | 匀速时 `pll_omega ≈ pll_integral`，±200rad/s = 1910rpm | 改 ±380rad/s（3630rpm） |
| 上位机按钮遮住输入框 | 使能/校零四个按钮盖住规划速度/加速度 | 按钮用了 grid 第 5 行，和新增的规划参数同格 | 按钮移到第 7 行，量坐标确认无重叠 |
| 上位机自测失败 | `struct.error: expected 46 items (got 42)` | 自测假帧还是温度字段加入前的旧格式；`CMD_PAYLOAD=46` 也是旧值 | 补 4 个温度字段；`CMD_PAYLOAD = struct.calcsize(CMD_FMT)` |

### 关键结论（备查）

- **死区误差符号**：`V_act = V_ideal − (Td/Ts)Vbus·sign(i)`，补偿量 `+(Td/Ts)Vbus·sign(i)`。
- **ZOH 影响**：离散激励的相位滞后 `−180°·f/fs`、幅值衰减 `sinc(πf/fs)`；电流 2kHz@20kHz 时 −18°。
- **PLL 更新率 ≠ 带宽**：20kHz 更新只决定采样比，相位滞后由 `ωn` 决定。
- **位置环级联**：`Kp ≤ 速度环带宽/3~5`；30Hz 速度环下 Kp=100（15.9Hz）偏激进。
- **ADC 低边窗口**：三通道采样需要 `duty_min > 序列长度/(25µs)`；47.5 周期要求 21%，24.5 周期要求 14%。
